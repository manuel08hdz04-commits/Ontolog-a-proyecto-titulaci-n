La incertidumbre se refiere al **grado de duda o falta de precisión que existe sobre el valor real de algo que estamos intentando medir, detectar o estimar**.

En la **fusión de sensores**, la idea central es que ningún sensor es perfecto. Cada uno puede cometer errores, pero si combinamos varios sensores que observan el mismo fenómeno desde diferentes perspectivas, podemos obtener una estimación más confiable.

# Incertidumbre ≠ error

Es muy importante diferenciarlos.

### Error

El **error** es la diferencia entre el valor medido y el valor verdadero

### Incertidumbre

La incertidumbre expresa **qué tanto desconocemos el valor verdadero**.

## Por qué los sensores tienen incertidumbre?

Porque un sensor real nunca es perfecto.

Existen diferentes fuentes de incertidumbre.

### 3.1 Ruido

Son pequeñas variaciones aleatorias en la medición.

### 3.2 Resolución

Es la capacidad del sensor para distinguir cambios pequeños.

### 3.3 Error de calibración

Un sensor puede estar descalibrado.

### 3.4 Condiciones ambientales

El entorno puede afectar las mediciones.

Por ejemplo:

- temperatura
- humedad
- presión
- iluminación
- vibraciones
- interferencias electromagnéticas
- obstáculos
- ruido acústico

Dependiendo del sensor, estos factores pueden modificar considerablemente las mediciones.
